# Preserve non-executing emulation as Fyke's core boundary

Fyke will remain a safety-first, mostly unattended honeypot for a single dedicated VPS. Attacker input will be interpreted by an emulated environment rather than executed by a host or container shell; richer engagement and deep research features must come from captured evidence while preserving that boundary. Multi-tenancy, fleet management, active cloud enrichment, executable extensions, and attacker-executable containers are outside the core product. Packet capture and public IPv6 are also outside the public-beta scope. A separate high-interaction system may be reconsidered only as an explicit, isolated product because its operational and security model would be materially different.
