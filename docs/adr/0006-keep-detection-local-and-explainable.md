# Keep detection local and explainable

Fyke will derive Findings from transparent, versioned deterministic rules with safe defaults and bounded Operator configuration rather than opaque scoring or programmable rule code. It may correlate repeated secrets through controller-keyed, domain-separated tokens that expire with the underlying Evidence, but it will never index the secret value or expose the token. Source enrichment will remain optional and offline, and only explicitly enabled Findings will produce deduplicated, rate-controlled Alerts.
