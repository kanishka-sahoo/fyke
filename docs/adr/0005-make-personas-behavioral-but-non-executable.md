# Make Personas behavioral but non-executable

Persona v2 will use a typed declarative schema for bounded command and HTTP state machines, with curated built-in packs and validated local packs. The Emulated Environment will support common interactive shell grammar, coherent Persona-derived outputs, bounded Session-seeded variation, realistic terminal behavior, and high-signal discovery, staging, and persistence commands. It will preserve virtual state for one Session and simulate Persona-defined network outcomes, but Persona content cannot execute code, render through a general template engine, fetch remote content, or persist mutable state across Sessions. Unsupported behavior will become an internal Emulation Gap and receive a plausible external error rather than revealing Fyke.

HTTP behavior will use bounded opaque-cookie state, deterministic typed route matching, and declared context-aware substitutions rather than unrestricted regular expressions or templates. Submitted field names and safe structure may be indexed, while values and raw bodies remain size-limited encrypted Evidence whose access is audited.
